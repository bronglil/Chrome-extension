Everything in one place

One extension, the whole workflow

Smart capture

Visible area, drag-to-select, and full-page scroll-and-stitch — no share picker, handles sticky headers and lazy images.

Screen recording

Record screen or window to WebM with optional mic and tab/system audio. Start and stop from the toolbar.

Full annotation editor

Arrows, shapes, freehand, highlighter, text, step counter, spotlight, blur/pixelate, plus gradient backgrounds and shadows.

Offline OCR

Extract text with Tesseract.js — preprocessing (upscale, contrast, Otsu) makes small and low-contrast text readable.

PDF sign & markup

Open a PDF, drop your signature exactly where you want, pen and highlight while you read, and export with the original text intact.

Share via QR

The popup shows a live QR of the current page — copy the link, copy or save the QR, or use the native share sheet.

Install (load unpacked)

Get the code

Download the latest release ZIP, or git clone the repo.

Open extensions

Go to chrome://extensions and turn on Developer mode.

Load unpacked

Click Load unpacked and pick the folder with manifest.json.

Pin & go

Pin SnapShot Studio to the toolbar and start capturing.
